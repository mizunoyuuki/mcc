void「値を持たない」という意味の特殊な型。

三つの用途がある。

----- 
1. 戻り値なしの関数
void print_hello(){
  printf("Hello\n");
  return;
}

2. 引数なし関数

int get_value(void){
  return 42;
  }

3. void * (汎用ポインタ)

void *ptr;
int x = 10;
ptr = &x;
ptr = "hello";
-----

voidは型のsemanticsを理解する上で必要

void型の汎用ポインタは、そのままのでリファレンスを禁止する。
なぜかというと、ポインタを外して何バイト読み込むのか決まっていないため。

不完全型とは

完全な型:
 int, char, struct { int x; }
 コンパイラがsizeof を計算できる

不完全な型(Incomplete Type)
void, struct User(前方宣言), int array[];(サイズ未指定の配列)

汎用ポインタ
- どんな型のポインタからも void *へ、キャストなしで代入できる。
- void* から他のポインタへ、キャスト無しで代入できる。(C++ ではNG, CではOK)
- そのままでは、デリファレンスができない。
- ポインタ演算ができない(p + 1)ができない。


void型は、不完全型の一種

不完全型とは、識別子は存在するが、サイズが確定していない型のこと
typedef struct Node Node;

Node *はできるけど、Nodeを型としては使えない.


### 不完全型は、その型で変数定義ができない。

void a;

変数は定義するとき、それは変数の領域を確保する。Type構造体を作って、TypeRegistryに保存されているsizeoffsetを入れる。
void型などの不完全型では、サイズがないので確保できない。なので言語仕様としてコンパイルエラーになる。


void型のポインタにchar型のポインタを入れるとどのような挙動になるか。

void *ptr;
char *s = "Hello";
ptr = s;
// ptrの型はまだvoid *
// コピーされるのはアドレスだけ。(8バイト)

C言語で型は変数のプロパティであり、値のプロパティではない。
代入は、「どんなデータをメモリに入れるか」であって、「そのメモリの型が何か」はわからない。
